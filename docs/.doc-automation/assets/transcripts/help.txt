# 采集时间：2026-09-20  环境：Windows 11 / mp 0.5.3

$ mp.cmd --help
mp — temporary authenticated preview of a local app, for phone-based AI workflows

usage: mp <command> [options]

commands:
  start               Expose the local app on a temporary authenticated public url
  capture             Screenshot the app at phone size and report what went wrong on the page
  status              List active previews and how long each has left
  stop                Tear a preview down and make sure nothing is left running
  doctor              Check that everything mp needs is installed, on PATH and reachable
  secret ask          Send the phone a form for credentials the AI may use but never see
  secret wait         Block until the phone has submitted the form, then report names and fingerprints — never values
  secret run          Run one of the approved commands with the values in its environment; output comes back redacted
  secret status       List secret slots: fields, approved uses, time left — never values
  secret forget       Wipe a slot from memory now rather than at its TTL
  interaction ask     Put a question on the phone as a page, and get a link to hand over
  interaction wait    Block until the phone submits, then print the answer as JSON — a timeout is not an error
  interaction status  List open questions: stage, revision, how much is filled in so far
  interaction close   End a question now rather than at its TTL, and drop its answer

global options:
  -h, --help     Show this help, or `mp <command> --help` for one command
  -v, --version  Print the mp version

On Windows PowerShell, `mp` collides with the built-in Move-ItemProperty
alias — call `mp.cmd` there. `mp doctor` checks the rest of the setup.

$ mp.cmd start --help
mp start — Expose the local app on a temporary authenticated public url

usage: mp start [options]

options:
  --port <n>     Local port to expose — the port your app already listens on (default 5173)
  --ttl <min>    Minutes before the preview self-terminates (1–1440) (default 30)
  --grace <min>  Minutes the link stays exchangeable after its first use (0 = one-shot) (default the --ttl value, i.e. reusable until expiry)
  --dev          Expose a dev server rather than a build (larger attack surface)
  --json         Print one machine-readable JSON object on stdout instead of prose
  --help         Show this help

  --strict               Exit non-zero when the page had console errors or failed requests

$ mp.cmd secret ask --help
mp secret ask — Send the phone a form for credentials the AI may use but never see

usage: mp secret ask [options]

options:
  --purpose <text>       One line shown at the top of the form: what these values are for
  --field <NAME[:kind]>  A field to collect. kind is secret (default, masked, redacted from output), text (visible, not redacted — a bucket name) or multiline (a textarea — a PEM key) (repeatable)
  --use <command>        A command the AI intends to run with the values, e.g. "npm run deploy"; the user ticks each one on the phone (repeatable)
  --id <id>              Ask an existing slot to approve more --use commands instead of opening a new one; the values are not re-entered
  --ttl <min>            Minutes the values stay in memory once they arrive (1–1440) (default 120)
  --form-ttl <min>       Minutes the form link stays open (1–60) (default 30)
  --json                 Print one machine-readable JSON object on stdout instead of prose
  --help                 Show this help
